# CI AVS

AV install design studio — draw floor plans, place kit, route cables, and export sheets.

## Render (same as your other Super Grok apps)

GitHub: [Rawlincoln/ci-avs](https://github.com/Rawlincoln/ci-avs)  
Blueprint: [Apply on Render](https://dashboard.render.com/blueprints/new?repo=https://github.com/Rawlincoln/ci-avs)  
Live URL: [https://ci-avs.onrender.com](https://ci-avs.onrender.com)

Free plan, auto-detects `render.yaml`. First load after idle can take ~30s.

Open a project, search **Add equipment** on the drawing, then drag, rotate, and resize kit. Drawings stay on this device (no account required).
